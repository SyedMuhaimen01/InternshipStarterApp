# Internship Starter App

Internship Starter App is an Android application that demonstrates best practices for using the Android 12+ built-in splash screen along with Material3 
theming and smooth activity transitions. This app follows best coding practices, compatabile with latest sdk's versions and is built on MVVM architecture.

## Features

- **Built-In Splash Screen**  
  Leverages the Android 12+ splash screen API for a fast and native launch experience with a custom logo and background.
  
- **Smooth Transition Animations**  
  Implements fade in/fade out animations to ensure a smooth transition between the Splash and Home screen.
  
- **Modern Material3 Design**  
  Uses Material3 theming with both light and dark variants to provide a professional look.

- **MVVM Architecture**  
  Incorporates ViewModel and LiveData for managing UI-related data in a lifecycle-aware manner.

## Project Structure
  Modular structure, i.e. eac type of resource has its designated package and directiry and follows a hireacrchical approach.

- **Themes and Styles**  
  App is compatiable with both light and dark themes. 

- **Colors**  
  Custom color resources are defined in `res/values/colors.xml` to support both light and dark themes.
  
- **Value**
  The app displays random quotes to inspire users.
